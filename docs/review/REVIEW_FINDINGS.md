# PR review — findings and verdicts

**Review prompt:** our own structured prompt in `.claude/skills/review-pr/SKILL.md` (the workshop's prompt was not available — decision D-16). It was run by three `pr-reviewer` sub-agents in parallel against the full PR diff (`git diff main...HEAD`, 78 files), one per lens: **A** rule correctness R1–R5, **B** test quality, **C** layering / API / security / naming / docs.
**Judged by:** the main agent, finding by finding. Every finding has exactly one verdict: **fixed**, **dismissed** (with reason) or **deferred** (with reason and follow-up).
**Result after the fixes:** build 0 warnings / 0 errors · unit tests `Passed! - Failed: 0, Passed: 114` · e2e `1 passed` from a clean start · `openspec validate add-approval-limits-by-role --strict` valid · Stryker unchanged at 100 % (no Domain code changed by the fixes).

Earlier review rounds on the AI-written tests (`test-reviewer` sub-agent, findings T-01..T-08, all fixed and proven with hand-applied mutants) are in `docs/evidence/test-review-step1.md` and `test-review-step2.md`.
